# mng

TUI file manager written in C++.

## Dependencies

- [ncurses](https://invisible-island.net/ncurses/): TUI rendering & terminal inputs.

Found on the system automatically. If not present, CMake will fetch and build them from source.

## Usage

```bash
./mng [OPTION] <PATH>
```

Available options are depicted in `OPTIONS.md`.
