# Options & flags

| Long option          | Option | Argument | Default | Description                   |
| -------------------- | ------ | -------- | ------- | ----------------------------- |
| `--help`             | `-h`   | -        | -       | Show usage and exit.          |
| `--version`          | `-v`   | -        | -       | Print version.                |
| `--show-hidden`      | `-H`   | -        | -       | Show hidden files by default. |
| `--sort <method>`    | `-s`   | -        | -       | Display sorted entries.       |
| `--filter <pattern>` | `-f`   | -        | -       | Display filtered entries.     |
